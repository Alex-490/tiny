这次我们来手撕一个简化版 vector，按照 C++ 后端面试的要求来实现。

我建议不要一上来就写完整的 std::vector，而是分阶段实现。重点是掌握动态数组的内存管理、扩容、对象构造与析构，以及移动语义。
一、先明确我们要实现什么
vector 本质上是一个动态扩容的连续内存数组。

它最核心的三个成员变量：
T* data_;          // 指向动态分配的数组内存
size_t size_;      // 当前已经存放的元素数量
size_t capacity_;  // 当前总容量


注意两个概念：
- size：真正构造出来的元素数量。
- capacity：已经申请的原始内存能够容纳多少个元素。
这两个概念不能混淆。capacity 后面的内存还没有构造 T 对象。
二、实现路线
我们按照以下顺序实现：
阶段	功能	重要程度
1	默认构造、析构	必须

5	拷贝构造、拷贝赋值	核心
6	移动构造、移动赋值	核心
